Daily Market Review

Bagaimana struktur pergerakan harga di Timeframe tinggi (Daily/4H)? Apakah Ekspansi, Retracement, atau Konsolidasi?

Apakah harga perlu masuk FVG/Order Block dulu? Apakah di zona Premium atau Discount?

Apakah pergerakan sesuai narasi? Ada bagian yang terlewat atau FOMO?

Weekly Market Review & Outlook

Integrasi Otomatis Google Sheets

Kirim data review langsung ke Google Sheets secara real-time tiap kali disimpan.

💡 Cara Menghubungkan Google Sheets:

  1. Buka Google Sheets baru di sheets.new.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Hapus semua kode lama, lalu tempel (*paste*) kode Apps Script di bawah ini:
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["ID", "Type", "Timestamp / Date", "HTF Narrative / Profiling", "DOL", "POI / Arrays", "Bias / News", "Chart Link", "Gameplan", "Self Audit"]);
    }
    
    sheet.appendRow([
      data.id || '',
      data.type || '',
      data.timestamp || '',
      data.htf_narrative || data.weekly_profiling || '',
      data.dol || data.weekly_dol || '',
      data.poi || data.weekly_arrays || '',
      data.daily_bias || data.weekly_news || '',
      data.chart_url || '',
      data.gameplan || data.weekly_gameplan || '',
      data.audit || data.weekly_audit || ''
    ]);
    
    return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
  } catch(error) {
    return ContentService.createTextOutput("Error: " + error.toString()).setMimeType(ContentService.MimeType.TEXT);
  }
}
  1. Klik Deploy > New deployment.
  2. Pilih type Web app. Pada Who has access, wajib pilih Anyone (Siapa saja).
  3. Klik Deploy, izinkan akses akun Google, lalu *copy* URL Web App yang dihasilkan dan tempelkan pada kolom di bawah ini.
